Introduction:css rule Consists of selector and declaration 


        
Selector: It is used to select the HTML element that we want to style.

        
Declaration: It consists of a property and a value, which defines how the selected element should be styled.

        
Property: It is the aspect of the element that we want to change, such as color, font-size, or background.

        
Value: It is the specific setting for the property, such as red for color or 16px for font-size.

        
Example: In the rule h1 { color: red; font-size: 24px; }, h1 is the selector, color and font-size are properties, and red and 24px are their respective values.

        
CSS rules can be applied to HTML elements to change their appearance, such as changing the text color, font size, or background color.

How to apply css

There are three ways to apply CSS to HTML:

  1. Inline CSS: Using the style attribute within an HTML element.
  2. Internal CSS: Using a style block within the head section of an HTML document.
  3. External CSS: Linking to a separate CSS file using the link tag in the head section.

Backgrounds

CSS allows you to set background colors, images, and gradients for elements.

  • Background Color: Use the background-color property to set a solid color.
  • Background Image: Use the background-image property to set an image as the background.
  • Background Gradient: Use linear-gradient or radial-gradient functions to create gradients.
  • Background Attachment:The background-attachment property specifies whether the background image should scroll or be fixed
  • Background Position: The background-position property sets the starting position of a background image.
  • Background Size: The background-size property specifies the size of the background image.
  • Background Repeat: The background-repeat property specifies whether the background image should be repeated.

    • Borders

    You can style borders around elements using properties like border-width, border-style, and border-color.
