LISTS:in html lists are used to group related items together: there are three types of lists 

            1. Ordered List:displays an items in a numbered format.
            2. Unordered List:displays items in a bulleted format.
            3. Description List:used for defining terms and their descriptions.

            for order list and onorderlist each item is wrapped in a (li) tag.
            for description list each term is wrapped in a (dt) tag and each description is wrapped in a (dd) tag.
