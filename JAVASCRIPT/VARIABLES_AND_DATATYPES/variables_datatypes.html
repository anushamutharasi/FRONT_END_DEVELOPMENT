Variables: In javascript variables are container to store the data

Variables are used to store data values. In JavaScript, there are three ways to declare variables: using var, let, and const.

  • var: This is the traditional way to declare variables. Variables declared with var can be re-declared and updated.
  • let: This is a block-scoped variable declaration. Variables declared with let can be updated but not re-declared in the same scope.
  • const: This is also a block-scoped variable declaration. Variables declared with const cannot be updated or re-declared in the same scope, making them constant.
    •             
    What is Good?
    
let and const have block scope.

let and const can not be redeclared.

let and const must be declared before use.

let and const does not bind to this.

let and const are not hoisted.


    What is Not Good?
    
var does not have to be declared.

var is hoisted.

var binds to this.

Data Types in js

JavaScript has dynamic typing, meaning variables can hold values of any type. The main data types in JavaScript are:

  • String: Represents a sequence of characters, enclosed in single or double quotes.
  • Number: Represents both integer and floating-point numbers.
  • Boolean: Represents a logical entity and can have two values: true or false.
  • Object: A collection of key-value pairs, where keys are strings and values can be any data type.
  • Array: A special type of object used to store ordered collections of values.
  • Null: Represents the intentional absence of any value.
  • Undefined: Indicates that a variable has been declared but has not yet been assigned a value.
  • Function: A callable object that can be executed to perform a specific task.
  • BigInt: Represents integers with arbitrary precision, useful for very large integers.
  • Symbol: Represents a unique and immutable value, often used as object property keys.
  • Symbol: A unique and immutable primitive value, often used as object property keys.
  • BigInt: A numeric data type that can represent integers with arbitrary precision, useful for very large integers.
